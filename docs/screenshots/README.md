# Screenshots

The README's feature images. When retaking them:

- Show a good day: well-known names, real prices, mostly green on the short horizons. Readers should judge the product, not the market.
- Use the dummy account (about $50k, in USD), never real holdings.
- Pick a moment with a full trading session behind it, so no intraday chart is empty or flat.
- Show time gaps across different scenarios: markets on different clocks (US, Asia, Europe) and crypto.
- Keep news, events and statements consistent with that moment, so nothing reads as future or stale.
- Use one theme, size and scale throughout, so the images read as a set.
